Sage

Website · AI

A web app that turns your interests into career suggestions, with the reasons behind each match and a first step to take.

See it live (opens in a new tab) GitHub (opens in a new tab)
Kind
Web app
Built with
Next.js, React, TypeScript, Tailwind CSS, Postgres, Gemini, Stripe
Made by
Danil Abramitov, with an AI coding assistant

The challenge

Choosing a career from a list of job titles is difficult. Sage starts with what people already enjoy.

How it works

Users describe their hobbies in a few words, and Google's Gemini AI suggests matching careers. The full report covers a typical day, the path into the job, and a plan for the first four weeks.

Design choices

Personal reasoning
Every match is explained in the user's own words, so the reasoning is easy to follow.
One next step
Every career suggestion ends with one clear action to take.
Value before sign-up
Users see real results before they create an account.

Key features

  • Free preview with three careers, without sign-up or payment details
  • User accounts that save every search
  • Monthly and yearly plans with a 7-day trial, powered by Stripe
  • Available in English, Spanish, French, German, and Russian

The result

A live web app that anyone can try in the browser, available in five languages.

Tad Off

Website · Game

A daily game that measures your instincts. Five quick games a day, the same for everyone.

Play it (opens in a new tab) GitHub (opens in a new tab)
Kind
Browser game
Built with
TypeScript, Vite, Vitest, Playwright
Made by
Danil Abramitov, with an AI coding assistant

The challenge

Create a game that people understand in seconds, finish in about 90 seconds, and have a reason to come back to the next day.

How it works

Each day brings five quick games. Players judge things such as a time, a length, an angle, or the number of dots in a crowd, and then see exactly how far off they were.

Design choices

One fair score
Every miss is measured in tads, so results from very different games can be compared.
No sign-up
There are no accounts, ads, or analytics. Results stay in the player's browser.
A measuring tape look
Tick marks, large numbers, and one strong colour for every error.
Open to more players
Light and dark themes, reduced motion support, and an option to skip a game.

Key features

  • Twelve instinct games and eight brain games
  • Last Inch, a survival mode on a tape of 100 tads
  • Pass and play for two to six people on one screen
  • Challenge links for playing the same day against a friend
  • Can be installed and played offline

The result

A live daily game that anyone can play in the browser, without an account.

Bunker 7

Game · Team project

A survival game for the browser. Players have seven days to build a radio and get rescued.

Play it (opens in a new tab) GitHub (opens in a new tab)
Kind
Browser game
Built with
Godot, GDScript
Made by
A team of four: Hleib, Ben, Sinan, and Danil

The challenge

Create a game for a game jam as a team of four, based on the theme "Bounce Back".

How it works

The player is the last survivor in Bunker 7. Each day they leave the bunker to collect wood, scrap, and circuits among the zombies and bring them home to build the radio.

Design choices

The theme as a rule
After each death the player bounces back to the bunker, but only a limited number of times.
Radiation as a timer
It grows stronger with distance from the hatch, and the Geiger counter ticks faster.
Limited space
A small backpack makes players decide what is worth carrying home.
A home to explore
The bunker is a place to walk through instead of a menu, and players earn back its rooms.

Key features

  • One clear goal: finish the radio beacon and survive until day 7
  • Thirst, hunger and radiation to manage on every trip
  • Random night events, such as a rain shower, a trader rat, or a horde at the door
  • Two additional areas to explore: the Old Mine and the Bomb Crater
  • Three difficulty levels

The result

A finished survival game that runs in the browser, published on itch.io.

Today

Website

A calm daily planner that keeps tasks, habits, and a focus timer on one page.

See it live (opens in a new tab) GitHub (opens in a new tab)
Kind
Daily planner website
Built with
HTML, CSS, JavaScript
Made by
Danil Abramitov, with an AI coding assistant

The challenge

Create a planner for a single day that is fast, calm, and leaves nothing to learn, without turning it into a productivity dashboard.

How it works

Users write one to three tasks, tap their habits as they go, and start a focus timer. Finishing something each day grows a streak, which the calendar shows together with a weekly review.

Design choices

One page for one day
Tasks, focus, and habits stay together, with a separate tab for tomorrow.
Forgiving streaks
Rest days and skipped days keep a streak safe, and habit strength allows for the occasional missed day.
Private by default
All data stays in the user's browser, with a backup file to save or restore it.
Comfortable to read
Adjustable text size, high contrast, and a less motion setting.

Key features

  • Tasks with drag to reorder and carry-over of unfinished ones
  • Up to eight habits with chosen weekdays, streaks, and a strength score
  • Focus timer from 1 to 180 minutes
  • Available in English, Russian, Spanish, French, German, Portuguese, and Ukrainian
  • Can be installed as an app and used offline

The result

A live planner that anyone can use in the browser, available in seven languages.
